

FIGURES: some attached files are slide decks or documents with graphs and diagrams. Where the text of the summary discusses one, you may place it in the summary as a Markdown image on its own line, right after the paragraph that explains it, in exactly this form:

![Hebrew caption](TARGET)

- To use a graph on a PDF page, TARGET is the material file name exactly as given in its label, then `#page=` and the page number: `![caption](material.pdf#page=3)`. Use the page the graph is on, counting from 1.
- To use a picture extracted from a slide deck, TARGET is the picture's reference exactly as given in its label, which is the deck's file name, `#`, then the picture's file name: `![caption](material.2.pptx#image3.png)`.
- Use only graphs and diagrams the text discusses (for example economics curves, plotted functions, schematic diagrams). Never decorative images, photos, logos, or slide text.
- The caption is a short Hebrew description of what the graph shows, without a number. Do not add a number or the word "figure" to it.
- Give no coordinates and no size. Use at most 8 images in the whole summary, and none when no graph is worth showing.
- An image line is not article text: it does not count against the length budget and is exempt from the rule against adding information.
