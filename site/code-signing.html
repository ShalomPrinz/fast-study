פרטיותPrivacy

FastStudy שולחת מידע רק למקומות שמפורטים כאן. מעבר להם היא לא מעבירה שום מידע למערכות אחרות ברשת, אלא אם מבקשים ממנה. FastStudy sends information only to the places listed here. Beyond them, it transfers no information to other networked systems unless you ask it to.

  • Groq מקבל את האודיו של ההרצאה כדי לתמלל אותו, עם מפתח ה־API שלכם. מדיניות הפרטיות של Groq Receives the lecture's audio to transcribe it, using your own API key. Groq's privacy policy
  • Gemini מקבל את התמליל, קובצי PDF שבחרתם להוסיף, ולסקירת הקורס קטעים מההרצאות, כדי לכתוב סיכומים, עם מפתח ה־API שלכם. תנאי Gemini API Receives the transcript, any PDF files you chose to add and, for a course overview, excerpts of its lectures, to write summaries, using your own API key. Gemini API terms
  • Google Drive ה־PDF של הסיכום עולה ל־Drive שלכם, רק אם הפעלתם העלאה ל־Drive. מדיניות הפרטיות של Google The summary PDF is uploaded to your own Drive, only if you turned Drive upload on. Google's privacy policy
  • דוחות שגיאהError reports כשמשהו נכשל, נשלח ל־Sentry דוח עם הודעת השגיאה, מיקומה בקוד, הגרסה, מערכת ההפעלה וסוף יומן ההפעלה של האפליקציה. לפני השליחה מוסרים ממנו נתיבי תיקיות, טקסט בעברית, שם המשתמש והמחשב ומפתחות API. הדוחות פועלים כברירת מחדל, ואפשר לכבות אותם במסך הפתיחה הראשון ובהגדרות; השינוי חל אחרי הפעלה מחדש. מדיניות הפרטיות של Sentry When something fails, a report goes to Sentry with the error message, where in the code it happened, the app version, the operating system and the end of the app's launch log. Folder paths, Hebrew text, your user and computer names and API keys are removed before it's sent. Reports are on by default, and you can turn them off on the first-run screen and in Settings; the change applies after a restart. Sentry's privacy policy
  • עדכוניםUpdates בכל הפעלה האפליקציה בודקת ב־GitHub Releases אם יש גרסה חדשה, ואם יש, מורידה אותה ברקע ומתקינה כשסוגרים את האפליקציה. מדיניות הפרטיות של GitHub Each time it starts, the app checks GitHub Releases for a new version, downloads it in the background if there is one, and installs it when you close the app. GitHub's privacy statement
