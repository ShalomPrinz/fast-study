מדיניות פרטיותPrivacy policy

FastStudy רצה על המחשב שלכם. ההרצאות, התמלילים והסיכומים נשארים בתיקייה שבחרתם. אין חשבונות, פרסומות או מעקב אחרי השימוש, ושום מידע לא נמכר. FastStudy runs on your computer. Your lectures, transcripts and summaries stay in the folder you chose. There are no accounts, ads or usage tracking, and nothing is sold.

שירותי צד שלישיThird-party services

FastStudy שולחת מידע רק לשירותים שהגדרתם בעצמכם: FastStudy sends data only to services you set up yourself:

  • Groq מקבל את האודיו של הרצאה כדי לתמלל אותה. מדיניות הפרטיות של Groq Groq gets a lecture's audio to transcribe it. Groq's privacy policy
  • Gemini מקבל את התמליל וכל קובץ PDF שמוסיפים, כדי לכתוב את הסיכום. תנאי Gemini API Gemini gets the transcript and any PDFs you add, to write the summary. Gemini API terms
  • Google Drive מקבל את ה־PDF של הסיכום, ורק אם הפעלתם העלאה ל־Drive. מדיניות הפרטיות של Google Google Drive gets the summary PDF, and only if you turned Drive upload on. Google's privacy policy
  • אתר האוניברסיטה — גישה לתוכן הקורסים שנבחרו בלבד, והגישה מוגבלת לקריאת תוכן בלבד. University website — access is limited to the content of the courses you chose, and is read-only.

כל שירות מטפל במידע לפי מדיניות הפרטיות שלו, ומפתחות ה־API שלכם נשמרים מוצפנים במחשב הזה. Each service handles the data under its own privacy policy, and your API keys are stored encrypted on this computer.

דוחות שגיאהError reports

כשמשהו נכשל, FastStudy שולחת דוח ל־Sentry. הוא כולל את השגיאה, את המקום בקוד שבו היא קרתה, את גרסת האפליקציה, את מערכת ההפעלה ואת סוף יומן האפליקציה. נתיבי תיקיות, טקסט בעברית, שמות המשתמש והמחשב ומפתחות API מוסרים לפני השליחה. מפתחות ה־API נשארים כל הזמן מוצפנים במחשב שלכם, נשלחים רק לשירות שהנפיק אותם, ולעולם לא נשלחים לאף שירות חיצוני אחר. הדוחות משמשים רק לתיקון באגים, ו־Sentry שומרת אותם לזמן מוגבל. אפשר לכבות אותם בכל רגע בהגדרות, ומאותו רגע לא נשלח שום דבר נוסף. מדיניות הפרטיות של Sentry When something fails, FastStudy sends a report to Sentry. It contains the error, where in the code it happened, the app version, your operating system and the end of the app's log. Folder paths, Hebrew text, your user and computer names and API keys are removed before it's sent. Your API keys always stay encrypted on your computer, are sent only to the service that issued them, and are never sent to any other external service. Reports are used only to fix bugs, and Sentry keeps them for a limited time. You can turn them off at any time in Settings, and nothing more is sent from that moment on. Sentry's privacy policy
