# מבוא למבני נתונים

## מה נלמד בשיעור

- מהו מבנה נתונים ולמה הבחירה בו משנה
- מערך מול רשימה מקושרת
- איך בוחרים מבנה לפי הפעולות הנפוצות

## מהו מבנה נתונים

מבנה נתונים הוא דרך לארגן מידע בזיכרון כך שהפעולות הנדרשות יהיו יעילות. אותו מידע יכול להישמר במבנים שונים, וכל מבנה קובע את זמן הריצה של כל פעולה.

## מערך ורשימה מקושרת

| פעולה                  | מערך     | רשימה מקושרת |
| ---------------------- | -------- | ------------ |
| גישה לפי אינדקס        | $O(1)$   | $O(n)$       |
| הכנסה במקום ידוע       | $O(n)$   | $O(1)$       |
| מחיקה במקום ידוע       | $O(n)$   | $O(1)$       |

- **מערך** — האיברים שמורים ברצף, ולכן הגישה מיידית אך הכנסה באמצע מזיזה את כל מה שאחריה.
- **רשימה מקושרת** — כל איבר מצביע לבא אחריו, ולכן הכנסה ומחיקה זולות אך הגישה דורשת מעבר על הרשימה.

## איך בוחרים

אין מבנה שהוא הטוב ביותר תמיד. בוחרים לפי הפעולות שהתוכנית מבצעת בתדירות הגבוהה ביותר.

בשיעור הבא: סימון $O$ גדול וניתוח זמן ריצה.
