# משתנים וטיפוסים

## מה נלמד בשיעור

- מהו משתנה ואיך מגדירים אותו
- ארבעת הטיפוסים הבסיסיים בפייתון
- קלט ופלט עם `input` ו-`print`

## משתנים

משתנה הוא שם שמצביע על ערך בזיכרון. מגדירים אותו בסימן שווה: השם משמאל והערך מימין.

## טיפוסים בסיסיים

| טיפוס   | מה הוא מחזיק          | דוגמה    |
| ------- | --------------------- | -------- |
| `int`   | מספר שלם              | `42`     |
| `float` | מספר עשרוני           | `3.14`   |
| `str`   | טקסט                  | `"שלום"` |
| `bool`  | אמת או שקר            | `True`   |

> **טעות נפוצה:** חיבור מספר למחרוזת נותן שגיאה. ממירים קודם לטיפוס המתאים.

## קלט ופלט

- `print` מדפיסה ערך למסך.
- `input` קוראת שורה מהמשתמש ומחזירה **תמיד** מחרוזת, ולכן מספר צריך להמיר עם `int`.
