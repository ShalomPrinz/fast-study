# סיבוכיות זמן ריצה

## מה נלמד בשיעור

- הגדרת סימון $O$ גדול והשימוש בו לניתוח אלגוריתמים
- חיפוש לינארי מול חיפוש בינארי
- מתי משתלם למיין לפני חיפוש

## סימון O גדול

**הגדרה.** פונקציה $f(n)$ היא $O(g(n))$ אם קיימים $c > 0$ ו-$n_0$ כך שלכל $n > n_0$ מתקיים:

$$f(n) \le c \cdot g(n)$$

ההגדרה מתעלמת מקבועים ומאיברים מסדר נמוך, ולכן היא מתארת התנהגות אסימפטוטית בלבד.

## חיפוש

| אלגוריתם     | דרישה מהקלט | סיבוכיות    |
| ------------ | ----------- | ----------- |
| חיפוש לינארי | אין         | $O(n)$      |
| חיפוש בינארי | מערך ממוין  | $O(\log n)$ |

חיפוש בינארי משווה לאיבר האמצעי ומשליך חצי ממרחב החיפוש בכל צעד, ולכן מספר הצעדים לוגריתמי בגודל הקלט.

> **שימו לב:** חיפוש בינארי עובד רק על מערך ממוין.

## האם למיין לפני חיפוש?

מיון עולה $O(n \log n)$, יותר מחיפוש לינארי יחיד. המיון משתלם רק כשמחפשים במערך פעמים רבות.
